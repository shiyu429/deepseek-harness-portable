# DeepSeek Harness U 盘便携版

这是基于 DeepSeek 官方 dsh 0.2.1-rc.5 制作的第三方便携构建，便携版本 1.3.0，不是 DeepSeek 官方发布的安装包。

NTFS 运行盘沿用官方的“仅可查看”“工作区内修改”“完全权限”及对应审批规则，包内和电脑工作区均可选择。FAT32/exFAT 按用户确认使用明确标注的“当前账户权限（FAT32/exFAT）”，范围不限于工作区。所有模式均不会自动取得管理员权限。

## 开始使用

1. 把整个文件夹解压或复制到 NTFS、FAT32 或 exFAT 格式的 U 盘或移动硬盘，建议放在盘根目录下，例如 `U:\DSH-Portable`。
2. 双击 **DSH Portable.exe**。不需要安装 Node.js、Python、pnpm、PowerShell 7 或 Office，不需要管理员权限。
3. 按官方界面添加 API Key，或使用该官方版本支持的登录方式。模型对话需要联网及可用的模型服务额度。
4. 从官方工作区界面添加要处理的电脑文件夹，或选取 U 盘里的工作文件夹。

**凭据完全沿用官方格式和界面。** 文件位于 `data\dsh\.credentials.yaml`；本版没有额外加密或修改凭据内容。请保管好包含凭据、聊天和工作文件的 U 盘。

为方便换电脑、换 Windows 账户继续使用，便携目录中的 `data` 使用可跨账户访问的权限。此设置只作用于便携数据目录，不会套用到你选择的电脑工作文件夹。

## 退出、复制和换电脑

关闭窗口可能只是让程序进入后台。复制程序或拔盘之前，请从系统托盘或应用菜单选择 **退出 DeepSeek Harness 便携版**，等待程序完全退出，以停止任务并完成数据保存。本版不产生权限恢复任务；异常结束后也不需要回原电脑撤销临时授权。正在写入时拔盘仍可能丢失或损坏数据。

正常退出后，复制**整个文件夹**即可。不要只复制 EXE，也不要漏掉 `data`。换电脑、用户名或盘符后，便携包内部的聊天、设置和工作区会按新位置解析；包外的目录仍按外部工作区处理。正在运行的任务不能直接搬到另一台电脑继续运行。

电脑上的原工作文件仍在原电脑，不会因为复制 dsh 而自动带走。原文件夹不可用或身份不符时，本版会阻止继续使用该目录，不会自动打开另一台电脑上的同名文件夹。

## 工作文件换了位置

U 盘内部的工作区自动按相对位置定位，无需重新选择。包外工作区同时检查原电脑身份及目录身份；另一台电脑即使存在同名、同路径的文件夹，也不会自动接管。

原工作区不可用时，先停止文件操作。需要继续时，在官方界面明确选择当前实际使用的文件夹。没有独立的“重新定位工作区”维护功能。聊天记录保存在 U 盘的 data，不能依靠模型识别选错的目录；工作文件也不会自动随聊天复制。

## 更新与中断续装

1. 从应用菜单或托盘完整退出便携版，等待任务和保存结束。
2. 下载最新的 **完整版 ZIP**。打开 **DSH 维护工具.exe → 安装与更新**，选择 ZIP 并点击“检查并安装”。无需另外下载更新包。
3. 等待同一窗口显示完成。新程序校验通过后才切换版本，聊天、凭据等用户数据保留在原来的 `data`；不会复制、备份、迁移或转换这些数据。

若安装中断，打开维护中心并点击“继续安装”。存在未完成任务时，工具会阻止重复创建安装任务。程序缺失时也不要删除 `data`，先继续安装或用完整的兼容程序包修复。

安装完成后自动清理已确认属于本程序的旧版本，包括其中的 Office 运行库。文件被占用时会显示清理待办；关闭相关程序后，到“程序检查”点击“清理旧程序与安装缓存”。此功能不清理未知文件夹或用户数据。

也可以完全退出后解压合并程序文件，保留 `data`；请勿先删除整个旧目录。建议使用维护中心安装，以便自动清理旧程序。

只支持经确认兼容的数据格式。未来官方改变格式时，维护工具会拒绝不兼容更新；不能承诺所有将来版本都能直接覆盖或随意降级。本次没有改变官方会话、凭据或数据库格式。程序文件和用户数据分开保存，更新需为暂存的新程序预留空间，工具按实际解压体积检查。

启动会核对程序文件并显示圆环和当前检查进度，慢速 U 盘可能需要数十秒。此机制不提供断电、磁盘故障或误删除的数据恢复保证。程序运行或保存时请保持磁盘连接。

## 统一维护工具与目录

根目录只有两个入口文件 **DSH Portable.exe**、**DSH 维护工具.exe**，以及必需的 **app** 和 **data** 文件夹。图标已嵌入两个 EXE，没有根目录外置图标或批处理脚本；用户无需执行图标检查。

维护工具提供四个页面：

- **概览**：查看版本并启动 DSH。
- **安装与更新**：选择最新完整版 ZIP，核对完整性、空间和数据兼容性；中断后在同一窗口继续安装。
- **程序检查**：核对程序及自带运行环境，重试清理旧程序和已记录的安装暂存。文件损坏时重新安装兼容完整版。
- **数据与说明**：打开 data 或使用说明。

覆盖更新不依赖数据备份或迁移。回退程序同样需要满足数据格式兼容检查，不能仅凭版本号认定可以回退。更新暂存和已有程序版本需要额外磁盘空间，工具按更新包实际大小检查。

本版不调用官方安装器更新，不注册系统 `dsh://` 协议，也不向系统 PATH 安装命令。高级命令入口为 `DSH Portable.exe --portable-cli`；运行命令前应先退出桌面版。

## 工作区与权限

建议把随盘使用的文件放在 data/workspaces 下的独立项目文件夹。选择“工作区内修改”时，官方 Windows 沙箱给所选工作区添加受限进程所需的权限和安全标签。电脑上的工作区也会发生这类调整；工作区授权按官方设计保留，退出时不恢复。

“仅可查看”和“工作区内修改”保留官方审批流程；“完全权限”不使用工作区沙箱，并沿用官方减少审批的规则。权限不能超过当前 Windows 账户本身拥有的权限。

便携版自己的 data 另外使用跨账户访问权限，并固定其权限继承、收窄 Everyone/登录身份的写入允许项，使 U 盘上的受限任务不会因为宽泛的父目录授权绕过写入限制。这项便携数据设置不会应用到所选电脑工作区；电脑工作区由官方沙箱授权。

授予工作区写入权限前，便携版额外检查 Everyone/登录身份的宽泛写权限、指向工作区外的目录链接或硬链接，以及不兼容的安全标签。受保护的私有子目录保留其原有权限，不再使整个工作区停用。当前用户拥有的工作区根目录缺少标签设置权限时，只为该用户补齐该目录不继承的 WRITE_OWNER，不改所有者。遇到其他上述情况明确停止授权，不会静默改为完全权限。请使用权限正常的独立项目目录，不要随意放宽整盘权限。中断造成的部分授权会在下次使用该工作区时检查并补齐，这不是退出后权限恢复。

Windows 沙箱保留上游的部分隔离范围，不能限制所有读取及网络行为，也不是完整虚拟机。上述检查不能承诺抵御任意并发文件替换、任意第三方插件或所有 Windows 权限组合。

## 支持范围

- Windows 10/11 x64、NTFS/FAT32/exFAT 运行盘，系统具有 .NET Framework 4.8 或更新版本，普通桌面用户权限；未覆盖 Windows ARM、macOS、本地离线模型。
- NTFS 的工作区权限模式和审批规则沿用官方，不按包内、包外限制选择；FAT32/exFAT 使用明确标注的账户模式。不自动安装系统服务、驱动、任务或开发工具。
- 程序、缓存、临时文件和应用配置保存在便携目录。Windows 自身的运行记录不属于无痕保证。
- 自带官方办公环境；Git、Docker、Visual Studio 等额外开发工具以及任意第三方插件不属于预装及兼容保证。
- 上游仍处于预发布阶段。本版保留其 Windows 受限执行机制的能力边界。

请核对下载文件校验值。受单位应用控制策略限制的电脑可能拒绝运行本构建。

## 运行环境与 FAT32/exFAT

双击后立即显示启动等待窗口及实际文件检查进度，主窗口出现后自动关闭。完整校验仍会读取程序文件，慢速 U 盘上可能需要数十秒。

NTFS 保留官方权限模式。FAT32/exFAT 按用户确认使用当前 Windows 账户执行文件操作与命令，权限选择器明确显示“当前账户权限（FAT32/exFAT）”，其范围不限于工作区；不把该模式标成受限写入。从 NTFS 搬到 FAT32/exFAT 后，旧会话也使用此项；搬回 NTFS 后恢复配置中的官方默认模式。FAT32 单文件上限约 4 GiB。

修复 FAT 类文件系统不能用硬链接创建文件的问题，改用 Windows 同卷且不覆盖已有文件的发布操作。pnpm 使用真正的独立 Node，默认把 store/cache 放在项目内的 .dsh-cache/pnpm，使用复制与 hoisted 布局。搬移项目后修复本程序管理的 pnpm storeDir/virtualStoreDir 记录，不批量替换项目或聊天文本；已实测可离线继续安装。显式链接依赖及任意第三方安装脚本不保证兼容 FAT。

Python 的受限进程私有临时目录兼容处理只在实际受限令牌和已授权工作区/临时目录内生效，避免 0700 目录丢失能力授权。pip 的默认安装位置为当前受限工作区的 .dsh-python/site-packages；当前账户模式下为 data/python/site-packages。通过 Python 导入这些库，不会改写封存的应用环境。临时目录和缓存仍在便携数据中，项目内安装与缓存随项目保存。

自带 npm/npx，并补齐锁定版本的 setuptools、wheel、requests、pypdf 及其运行依赖。Python 命令入口使用相对路径。matplotlib、scipy 及 Git、pandoc、ffmpeg、7z、qpdf、完整 LibreOffice 不属于本版预装内容；可按任务安装额外工具。官方办公功能使用 libreoffice-kit，不伪造 soffice.exe。图像输入能力取决于所选模型。

办公渲染允许已有空目录，包含文件的目录仍拒绝覆盖。临时字体清理增加有限重试，持续失败仍如实报错，不隐藏失败。字体缺失信息保持真实，不能保证没有指定字体时版式完全一致。

Windows 系统模块路径可供便携 PowerShell 使用。NTFS 受限令牌下，Schannel HTTPS 和 CIM 存在上游限制，未通过放开权限或关闭证书校验来绕过。Node/Python 的 HTTPS 可用；需要 Schannel/CIM 的任务可由用户选择官方完全权限。参见[上游问题记录](https://github.com/deepseek-ai/deepseek-harness/discussions/2850)。本版不向 AI 注入环境报错提醒或规避指令。

实体 FAT32/exFAT、干净 Windows 10、跨电脑以及断电强拔仍需实机验收，不能用 NTFS 测试替代。

## 1.3.0 改进

pnpm 的查询、配置和存储命令不再收到安装专用参数；npm 不再收到 pnpm 的伪配置项。应用内工具优先，并保留电脑上已有 Git 等工具的路径，不更改系统 PATH。`dsh --version` 和 `dsh --help` 在受限模式中无需启动辅助进程即可显示官方内容。Python 退出时只清除本进程在私有临时目录创建的空 pip-* 目录。

启动页和维护中心使用纯白背景、矢量圆环及高 DPI 布局。维护窗口在安装和续装期间保持打开，禁止并发安装，并提供旧程序清理失败的提示和重试。
