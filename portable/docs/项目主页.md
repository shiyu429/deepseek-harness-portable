## 为什么选择这款便携版

适合希望在不同 Windows 电脑之间携带同一套 AI 工作环境，或不想反复配置 Node.js、Python 和 PowerShell 的用户。它把官方 Harness、运行依赖与应用数据放在同一个文件夹中，同时保留官方界面、模型接入、工具、会话和插件架构。

| 使用需求 | 这里的处理方式 |
| :--- | :--- |
| 新电脑上尽快开始 | 运行环境随包携带，启动无需重新安装这些依赖；模型服务仍需联网。 |
| 尽量少影响电脑环境 | 不注册系统服务、不写系统 PATH、不安装全局命令；环境设置只作用于应用及其子进程。 |
| 携带自己的工作 | 聊天、设置、凭据和默认工作区随 `data` 保存；包内工作区按相对位置解析。 |
| 直接处理原文件 | 可以选择电脑或移动磁盘上的实际目录，不必先把文件导入聊天。 |
| 更新后继续使用 | 程序与数据分开保存；同一已验证数据格式的更新保留 `data`，无需复制、备份或迁移数据。 |
| 知道运行的是什么 | 上游提交和依赖锁固定，源码、构建脚本、许可证与下载校验值可核对。 |

> **推荐将程序和需要受限写入的工作区放在 NTFS 磁盘上。** FAT32/exFAT 可以运行，但采用当前 Windows 账户权限，其命令写入范围不限于所选工作区。

## 三步开始

**① 下载并解压**

从 [发布页面](https://github.com/shiyu429/deepseek-harness-portable/releases/latest) 下载完整 ZIP，把其中的 `DSH` 文件夹解压到可写的短路径，例如 `D:\DSH`。请完整解压后启动，不要在 ZIP 内直接运行，也不要只复制 EXE。当前版本：**@VERSION@**。

**② 配置模型服务**

双击 **`DSH Portable.exe`**，在应用设置中添加模型服务，填写服务地址、模型标识与 API Key；具体字段以官方界面为准。自定义服务需兼容所选模型接口，模型额度由对应服务提供。本包包含运行环境，不包含离线本地模型。

**③ 添加工作区并开始对话**

选择实际需要处理的文件夹，再新建会话。希望工作文件随盘携带时，把工作区放在 `DSH` 文件夹内部。第一次启动会校验运行文件，慢速 U 盘可能等待较久，启动页会显示圆环与文件检查进度。

## 选哪种磁盘格式

![便携目录与权限选择示意图](portable/assets/portable-layout.svg)

下表按**程序所在磁盘**说明默认行为；目标工作区的文件系统和当前账户本身的访问权限也会影响执行结果。

| 项目 | NTFS · 推荐 | FAT32 / exFAT |
| :--- | :--- | :--- |
| 权限模式 | 沿用官方“仅可查看”“工作区内修改”“完全权限”及对应审批规则。 | 默认采用并明确显示“当前账户权限（FAT32/exFAT）”。 |
| 命令范围 | 官方受限模式依赖 Windows 权限机制；完全权限使用当前账户可访问的范围。 | 不具备 NTFS 的文件权限隔离；命令可能读写工作区之外、当前账户允许访问的位置。 |
| 操作审批 | 沿用官方规则。 | 保留操作审批，但审批不能代替文件系统隔离。 |
| 自动提权 | 不会自动取得管理员权限。 | 不会自动取得管理员权限。 |
| 文件大小 | 无 FAT32 的约 4 GiB 单文件限制。 | FAT32 单文件上限约 4 GiB；exFAT 不受该上限限制。本包内单文件均小于 4 GiB。 |
| 适合谁 | 希望使用官方工作区权限模式的 Windows 用户。 | 需要兼容现有磁盘格式，并接受当前账户执行范围的用户。 |

**关于工作区授权：** NTFS 的“工作区内修改”沿用官方对受限进程的工作区授权，这些授权会保留。本版不创建需要退出后撤销的临时权限，不需要在异常结束后回原电脑执行权限恢复。它不会把便携数据目录的跨账户权限套用到电脑工作区，也不会为运行程序重置整棵用户目录的权限。

**关于拔盘：** 没有权限恢复任务，不代表可以在运行或保存时强拔。写入中断仍可能损坏聊天、工作文件或文件系统；请等待任务停止并完整退出后再拔出。

## 文件放在哪里

```text
DSH/
├─ DSH Portable.exe       启动应用
├─ DSH 维护工具.exe        更新、检查与维护
├─ app/
│  ├─ bin/               官方程序与便携运行环境
│  └─ 说明与许可/          许可证、第三方声明、依赖与来源
└─ data/
   ├─ dsh/               会话、配置与官方格式凭据
   ├─ workspaces/        默认工作区
   ├─ desktop/           桌面应用设置
   ├─ browser/           浏览器会话数据
   └─ …                  插件、私有缓存、日志和临时文件
```

根目录保留两个 EXE 与 `app`、`data` 两个文件夹。图标嵌入 EXE，无需外置图标或批处理启动。便携包不附带使用说明文件，使用方法集中在本主页；[源码中的详细说明](portable/docs/使用说明.md) 可供查阅。

`data` 为跨电脑、跨账户使用而保存，不应依赖原电脑账户的文件权限来保密。凭据格式沿用官方实现，没有增加额外加密；请将包含聊天、凭据和工作文件的整个便携目录视为敏感数据妥善保管。

## 复制、换电脑与工作区

1. 先等待任务结束，从应用菜单或系统托盘选择退出。关闭主窗口可能仍在后台运行。
2. 复制整个 `DSH` 文件夹，包含 `app` 和 `data`，再到另一台符合要求的 Windows 电脑启动。
3. 包内工作区按相对位置解析，换盘符后无需重新选择；受管理依赖的路径记录会按新位置修复，不批量替换聊天正文中的路径文字。

电脑上的外部目录不会因为复制 DSH 而被带走。外部工作区同时核对原电脑和目录身份；另一台电脑即使存在同名、同路径的文件夹，也不会自动接管。原目录不可用时，请在官方工作区界面明确选择当前要处理的实际文件夹。聊天记录保存在本地 `data`，不能依赖模型判断目录是否选错。

正在运行的任务不能跨电脑搬迁；第三方插件和任意开发环境所需的额外工具，也不承诺自动便携化。

## 更新与统一维护中心

| 页面 | 可以做什么 |
| :--- | :--- |
| 概览 | 查看版本并启动 DSH。 |
| 安装与更新 | 选择最新完整版 ZIP，核对空间、文件完整性与数据兼容性；继续未完成的安装。 |
| 程序检查 | 查看校验进度及缺失、损坏文件；清理可确认归属的旧程序与安装缓存。 |
| 数据与说明 | 打开数据目录，查看便携位置，以及许可证与依赖来源。 |

**更新步骤：** 完整退出 DSH → 下载最新完整版 ZIP → 打开 **`DSH 维护工具.exe`** → 在“安装与更新”选择 ZIP → 点击“检查并安装”，等待同一窗口显示完成。

新程序校验通过后才切换。兼容更新不覆盖 `data`，不依赖数据备份或迁移；安装中断时使用“继续安装”，不要反复新建安装任务。完成后自动清理已确认属于本程序的旧运行文件；若文件仍被占用，会显示待清理项目，可关闭相关程序后重试。

只允许经过确认的数据格式。未来上游改变格式时，不兼容的更新会停止；不能仅凭版本号认定可以直接覆盖或降级。发布附件仅提供**完整版 ZIP 与 SHA-256 校验文件**，不需要单独下载更新包。

## 自带什么，还需要什么

| 随包携带 | 需要按实际任务准备 |
| :--- | :--- |
| Electron、Node.js、Python、pnpm、npm、PowerShell、官方办公库及必要原生依赖。 | 可用的模型服务、API Key、网络与服务额度。 |
| 与上述运行环境配套的固定依赖和许可信息。 | Git、完整 Office/LibreOffice、pandoc、ffmpeg 等额外工具，以及第三方插件的专用依赖。 |

pnpm 使用项目内存储和复制布局，pip 使用可写的便携安装位置；额外依赖下载仍需联网。本版不伪造未安装工具，也不替所选模型声明不存在的图像能力。特定字体未安装时，办公输出的版式可能受影响。

## 系统要求与实际边界

- **系统：** Windows 10/11 x64，.NET Framework 4.8；第一版不支持 macOS、Windows ARM。
- **存储：** 可写的 NTFS、FAT32 或 exFAT 磁盘；推荐 NTFS 与短目录。外部解压工具仍可能跳过过深路径，请完整解压。
- **环境：** 不写系统 PATH、注册系统服务或安装全局命令。用户授权执行的命令与插件仍可按实际权限修改对应位置，Windows 自身的运行记录不属于“无痕”保证。
- **系统接口：** 官方受限令牌下部分 Windows 系统接口及 Schannel 网络客户端存在限制；需要相应能力时，请理解权限范围后自行选择官方完全权限。
- **验证范围：** 已完成针对性启动、工作区、维护与模拟模型检查；干净系统、实体 FAT/exFAT、跨电脑与强拔的完整验收仍需继续。上游基线是预发布版，不将单机测试当作所有平台稳定性保证。
