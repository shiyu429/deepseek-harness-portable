# DeepSeek Harness Portable · DSH便携版

**把 DeepSeek Harness 和运行环境一起带走。**

Windows x64 · USB / 移动硬盘 · Node.js / Python / pnpm / npm / PowerShell · 官方办公能力

[下载最新版](https://github.com/shiyu429/deepseek-harness-portable/releases/latest) · [English](#english) · [构建说明](portable/README.md)

DeepSeek Harness Portable 是基于 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 的第三方便携构建。保留官方聊天界面、模型接入、工具、会话与插件架构，把运行依赖和应用数据放进同一个文件夹。当前便携版本 **@VERSION@**。

## 为什么使用 DSH便携版

- **启动不先装环境**：自带 Electron、独立 Node.js、Python、pnpm、npm、PowerShell 及官方办公运行依赖。模型请求仍需联网。
- **数据跟着文件夹走**：聊天、官方凭据、设置、插件、浏览器数据、缓存和默认工作区集中保存在 `data`。
- **不安装进电脑环境**：不注册系统服务、不写系统 PATH、不安装全局命令、不调用安装器自动更新。程序及子进程使用自己的环境设置。
- **保留官方工作方式**：NTFS 使用官方权限模式与审批规则；可以选择电脑上的实际项目目录。
- **包管理适配便携路径**：pnpm 使用项目内存储和复制布局；搬移项目后修复受管理的依赖路径记录。pip 默认安装到可写位置。
- **维护时数据留在原位**：白色原生维护中心提供完整包安装、续装、完整性检查和数据入口。兼容版本更新不备份、迁移或覆盖用户数据；新程序校验通过才切换。
- **运行文件可核对**：固定上游提交和依赖锁，提供源码、构建脚本与下载校验值。

## 三步开始

1. 在 Releases 下载最新的 `DSH-Portable-@VERSION@-win-x64.zip`，解压到可写目录，建议靠近盘根目录。
2. 双击 `DSH Portable.exe`，在官方设置界面配置模型服务及 API Key。
3. 选择工作区并开始使用。需要更新或检查程序时打开 `DSH 维护工具.exe`。

```text
DSH Portable.exe
DSH 维护工具.exe
app/                    程序、运行环境、必要说明和许可证
data/                   聊天、凭据、设置、插件和工作文件
```

## 复制与更新

先从应用菜单或托盘完整退出，再复制整个文件夹。U 盘内工作文件可随盘继续使用，电脑上的原文件夹不会自动带走；换电脑后应选择实际可用的目录。

维护中心接受最新完整版 ZIP，检查兼容性及文件完整性后更新。也可完整退出后解压合并程序文件，保留原有 `data`；不要删除整个旧目录。只支持已确认兼容的数据格式，未知格式会停止更新。

## 权限与适用范围

支持 Windows 10/11 x64，需要 .NET Framework 4.8。NTFS 沿用官方的仅可查看、工作区内修改和完全访问规则；工作区受限进程授权按官方设计保留，退出不做权限回滚。

FAT32/exFAT 不提供 NTFS 权限隔离，界面明确显示“当前账户权限”，命令范围不限于工作区。FAT32 单文件上限约 4 GiB。实体 FAT/exFAT、不同电脑及断电强拔没有完成全面验收；运行或保存时应保持磁盘连接。

Windows 受限令牌下部分系统接口及 Schannel 网络客户端受上游执行机制限制。图片输入由模型服务及所选模型的真实能力决定。第三方插件、额外编程工具及任意开发环境不承诺自动便携化。

凭据格式沿用官方实现，没有额外加密；请保管好整个便携目录。Windows 自身的运行记录不属于“无痕”保证。

## 源码与上游

`d/` 为包含便携改动的上游源码，`portable/` 为启动、维护、运行时兼容与构建代码。构建步骤见 [portable/README.md](portable/README.md)。上游基线为 `dsh-v0.2.1-rc.5`，提交 `b830ec950faba0a46dda564be3e2d854afed94f1`，没有自动跟随上游更新。

本项目不是 DeepSeek 官方发布的 Windows 安装包。保留上游及依赖许可证；具体归属见源码 LICENSE 与便携包 `app/说明与许可`。

## English

**DeepSeek Harness Portable brings DSH, its runtimes, and your application data together in one folder.** This community Windows x64 build preserves the upstream interface, model integrations, tools, sessions, and plugin architecture. Current portable version: **@VERSION@**.

### What it provides

- Bundled Electron, standalone Node.js, Python, pnpm, npm, PowerShell, and the upstream Office runtime. Startup does not download these dependencies; model services require an internet connection.
- Chats, upstream-format credentials, settings, plugins, browser data, caches, and default workspaces stored under `data`.
- No system PATH changes, global command installation, service registration, or installer-driven automatic updates. Environment changes apply to the application and its children.
- Upstream NTFS permission presets and approval behavior, with direct access to a selected local project folder.
- Project-local pnpm storage, copy-based dependency installation, and repair of managed dependency locations after a move. pip uses writable installation locations.
- A native white maintenance center for full-package installation, interrupted-install continuation, integrity checks, and data access. Compatible updates switch programs after validation while leaving user data in place.
- Pinned upstream sources and dependency locks, build scripts, and release checksums.

### Quick start

Download the latest full ZIP from [Releases](https://github.com/shiyu429/deepseek-harness-portable/releases/latest), extract it into a writable folder, and launch `DSH Portable.exe`. Configure your model service and API key in the upstream interface, then choose a workspace. Open `DSH 维护工具.exe` for maintenance.

Exit completely before copying the entire folder or updating. Keep `data`; local computer workspaces do not travel with the USB drive. The maintenance center accepts a compatible full ZIP and validates it before switching programs. Unknown data formats are rejected.

### Requirements and limits

Windows 10/11 x64 and .NET Framework 4.8 are required. NTFS uses upstream permission and approval rules; standing workspace grants remain in place without an exit-time rollback. FAT32/exFAT use an explicitly labelled current-account execution mode, which does not confine commands to the workspace. FAT32 has a per-file limit of approximately 4 GiB.

Physical FAT/exFAT media, cross-computer use, and abrupt removal have not received exhaustive validation. Keep the drive connected during execution and saves. Some Windows system interfaces and Schannel clients remain restricted by the upstream token mechanism. Image input requires a model that actually supports it. Arbitrary third-party plugins and development environments are outside the portability guarantee.

Credentials retain the upstream format without added encryption. Protect the entire portable folder. The application does not promise to suppress Windows-generated execution records.

### Build and attribution

The `d` directory contains the modified upstream sources, and `portable` contains the launcher, maintenance UI, runtime compatibility code, and build scripts. See [build instructions](portable/README.md). The upstream baseline is `dsh-v0.2.1-rc.5`, commit `b830ec950faba0a46dda564be3e2d854afed94f1`.

This is a third-party portable build, not an official DeepSeek Windows installer. Upstream and dependency licenses are preserved in the source tree and `app/说明与许可`.
