# 无需权限恢复的便携工作区

[English](guide.md) | 中文

## 变更

此项仅适用于第三方 Windows 便携构建，不改变上游默认发行行为。便携版 1.1.0 在包内通过固定授权保留 workspace-write，包外目录使用当前账户权限，包括账户有权修改的其他位置。只读仍可用。全新使用的包没有权限恢复命令，也不在启动或退出时扫描权限恢复记录。

## 迁移

1. 将完整 1.1.0 包解压到尚未使用的可写 NTFS 目录，从空白 data 开始使用。
2. 把随盘项目放进 `data/workspaces` 下的独立文件夹，确认权限选择器显示“工作区内修改”。
3. 打开包外目录时，确认选择器显示“当前账户权限”。包外显式选择 workspace-write 会在授权前拒绝。
4. 复制或拔盘前正常退出，完成数据写入。包内固定授权留在盘内，不需要退出恢复；突然拔盘仍可能中断文件写入。
