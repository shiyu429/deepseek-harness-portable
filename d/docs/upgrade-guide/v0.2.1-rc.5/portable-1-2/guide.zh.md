# 便携版 1.2 的权限与覆盖更新

[English](guide.md) | 中文

## 变更

第三方 Windows 便携构建使用上游权限预设服务和 Windows 沙箱提供方。包内和包外工作区均支持 read-only、workspace-write、danger-full-access 及上游审批规则。工作区授权按上游设计保留，不增加退出恢复。便携数据权限仍仅作用于应用自己的 data 目录。未经修改的 1.1 自动生成主配置会更新，去掉便携权限覆盖；自定义配置和历史权限事件保留。

程序文件放在独立版本的 app 目录，与 data 分开。启动器在启动任何数据写入进程之前，完整检查选定程序及其声明的数据格式。兼容覆盖包不包含 data 或 backups，不复制或转换用户数据。未知或改变的数据格式会阻止启动。此机制不恢复硬件故障或应用写入中拔盘造成的数据损坏。

根目录文件仅保留应用和图形维护工具两个 EXE；资源和说明保存在 app 下。维护工具安装兼容更新、继续中断的程序部署、校验程序文件并打开 data 或说明。内部工作区自动定位。外部工作区检查电脑及目录身份，用户通过上游工作区选择入口明确选择，不提供独立重新定位工具。便携长期授权在修改前拒绝宽泛的环境写权限或外部链接，并在再次使用时补齐中断的子项授权。

## 迁移

1. 完整退出便携程序。
2. 在维护工具中选择兼容的 overwrite-update.zip，或解压到原便携目录、合并覆盖程序文件。不要删除或整体替换该目录。
3. 启动 DSH Portable.exe。更新不完整时会被拒绝；保留 data 并重新覆盖完整兼容包。格式不兼容时应使用兼容版本，不能跳过检查。
4. 在会话中选择权限模式。完全权限保留上游风险确认。旧会话保留日志中的选择，直到用户明确切换。
